# Student Performance Data Analysis

This is my beginner-level Python project in which I analysed student performance using Pandas and Matplotlib.

## About the Project

I worked with a dataset containing 1,000 student records. I explored students' Mathematics, Reading, and Writing scores to understand their academic performance.

## Tools Used

- Python
- Pandas
- Matplotlib

## What I Did

- Loaded and explored the student dataset.
- Checked for missing values.
- Calculated average marks in different subjects.
- Found the highest and lowest scores.
- Analysed pass and fail percentages.
- Compared students' performance based on test preparation.
- Created charts to understand the results.

## Some Findings

- Average Mathematics score: 66.09
- Average Reading score: 69.17
- Average Writing score: 68.05
- Pass percentage: 97% (using a 40% average-score threshold).

## How to Run

Install the required libraries:

```bash
pip install pandas matplotlib
```

Run the project:

```bash
python student_analysis.py
```
